## Actual downloaded-file inspection

The SOFA sample reports `DataType=FIR`, `RoomType=shoebox`, `Data.SamplingRate=48000`, `Data.IR` shape `(1, 5, 48000)`, and five zero `Data.Delay` values. `SourcePosition` and `ReceiverPosition` explicitly declare metre units. Room corners are provided but omit a `Units` attribute; their approximately `(5.705, 5.965, 2.355)` span is interpreted in the SOFA room coordinate metre scale and is consistent with the paper's roughly `6 × 6 × 2.4 m` room. This interpretation is recorded in the output metadata. The source coordinate is approximately `(1.8941, 4.5219, 1.4482) m`; microphone coordinates are in the machine-readable run result.

The annotation file has `echo_toa` and `echo_wall` arrays of shape `(7, 30, 6)`, plus source and microphone positions and room dimensions. Rank 0 labels direct arrivals (`d`); ranks 1–6 are provider-annotated early echoes with wall labels. For source index 0 (named source 1) and microphone indices 0–4 (the five channels in the SOFA filename), BatSight copies the seven provider times and their original wall labels into [the provenance JSON](../experiments/phase6e_results/dEchorate_provider_annotations.json). The detector does not receive these labels.

## Suitability decision

The dEchorate subset passes the requirements for testing the existing calibrated direct-TOA candidate path and comparing unclassified peak candidates to independent early-echo labels **in the RIR domain**. It does not test the entire calibrated real recording chain: the SOFA file contains a measured RIR already estimated from an exponential sweep, while the probe, raw microphone waveforms, and loopback track are absent. A one-sample impulse reference makes the existing correlator operate on the RIR itself. This checks the existing correlation/peak/TOA code on real measured impulse responses; it cannot establish that BatSight matched-filters original probe recordings correctly.

The VGM dataset remains an unresolved acquisition candidate due to the HTTP 403 archive response and missing published license statement. The much larger dEchorate HDF5 archive (25.8 GB) was not downloaded; the evaluation uses only the small SOFA subset plus its 30 KB annotations file.
